# Proofboard

A public board for the verification history of a GitHub repository. Paste a repository URL and Proofboard reads the TestSprite checks on its pull requests: what ran, what passed, what failed, and the moment a failing run turned green after a fix.

Proofboard does not run tests. The runs are TestSprite's work, triggered by its GitHub App on pull requests. Proofboard reads those runs from the public GitHub record and gives them a permanent, linkable page.

Built during TestSprite Hackathon Season 4 (October 2026).
